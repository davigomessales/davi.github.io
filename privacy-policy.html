Política de Privacidade

Rclone

Última atualização: 26 de setembro de 2026

1. Introdução

Esta Política de Privacidade descreve como o aplicativo Rclone, desenvolvido por Davi Gomes de Sales, trata informações quando o usuário utiliza o aplicativo e suas funcionalidades que utilizam APIs do Google.

Ao utilizar o aplicativo, o usuário reconhece as práticas descritas nesta política.

2. Dados acessados por meio das APIs do Google

Dependendo das funcionalidades utilizadas e das permissões autorizadas, o Rclone pode acessar informações disponibilizadas pelas APIs do Google.

Essas informações podem incluir:

  • informações básicas necessárias para identificar a conta autorizada;
  • metadados de arquivos;
  • nomes, tipos, tamanhos e outras propriedades de arquivos;
  • conteúdo de arquivos quando a permissão concedida e a funcionalidade utilizada exigirem esse acesso;
  • informações necessárias para executar operações solicitadas pelo usuário.

O aplicativo somente solicita as permissões necessárias para as funcionalidades disponibilizadas.

3. Como utilizamos os dados

Os dados obtidos por meio das APIs do Google são utilizados para fornecer as funcionalidades do Rclone solicitadas pelo usuário, incluindo, quando aplicável:

  • acessar arquivos autorizados;
  • listar arquivos e respectivos metadados;
  • realizar operações de gerenciamento de arquivos;
  • sincronizar arquivos entre recursos autorizados;
  • executar operações solicitadas pelo próprio usuário.

O Rclone não utiliza os dados obtidos das APIs do Google para publicidade direcionada, venda de informações pessoais ou criação de perfis de publicidade.

O uso das informações recebidas das APIs do Google está sujeito à Google API Services User Data Policy, incluindo os requisitos de Limited Use.

4. Compartilhamento de informações

O Rclone não vende, aluga ou comercializa informações pessoais dos usuários.

Os dados obtidos por meio das APIs do Google não são compartilhados com terceiros para fins de publicidade ou comercialização.

Informações poderão ser divulgadas quando necessário para cumprir uma obrigação legal, ordem judicial ou determinação de autoridade competente.

5. Armazenamento e retenção

O Rclone procura limitar a retenção de informações ao período necessário para fornecer as funcionalidades solicitadas pelo usuário.

Quando os dados não forem mais necessários para a finalidade para a qual foram obtidos, eles deverão ser excluídos ou anonimizados, observadas eventuais obrigações legais de retenção.

Tokens ou credenciais de autorização poderão ser mantidos enquanto forem necessários para manter a autorização concedida pelo usuário e fornecer as funcionalidades correspondentes.

6. Exclusão de dados

O usuário pode revogar a autorização concedida ao aplicativo por meio das configurações da própria Conta do Google.

O usuário também pode solicitar a exclusão de dados eventualmente mantidos pelo aplicativo entrando em contato pelo canal indicado abaixo.

Após uma solicitação válida de exclusão, os dados serão excluídos quando não houver obrigação legal ou outra justificativa legítima para sua retenção.

7. Segurança

São utilizadas medidas técnicas e organizacionais razoáveis para proteger as informações contra acesso, alteração, divulgação ou destruição não autorizados.

A comunicação entre o usuário, o aplicativo e os serviços externos deve utilizar conexões seguras quando tecnicamente disponíveis.

8. Serviços do Google

O Rclone utiliza APIs fornecidas pelo Google. O uso dessas APIs também está sujeito às políticas e aos termos aplicáveis do Google.

O aplicativo solicita apenas as permissões necessárias para as funcionalidades que oferece e utiliza os dados obtidos dessas APIs de acordo com as finalidades apresentadas ao usuário.

9. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada para refletir alterações nas funcionalidades do aplicativo, nas práticas de tratamento de dados ou nas exigências legais e regulatórias.

A versão atualizada será disponibilizada nesta mesma página.

11. Conformidade com as políticas do Google

O uso de informações recebidas das APIs do Google pelo Rclone está sujeito à Google API Services User Data Policy e aos requisitos de Limited Use aplicáveis.

O Rclone não utiliza dados obtidos por meio das APIs do Google para publicidade direcionada, venda de dados ou outras finalidades incompatíveis com a finalidade de fornecer ou melhorar as funcionalidades voltadas ao usuário.
