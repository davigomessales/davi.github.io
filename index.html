Rclone

Integração para gerenciamento e sincronização de arquivos utilizando APIs do Google, mediante autorização do usuário.

Sobre o aplicativo

O Rclone é uma aplicação desenvolvida para facilitar o gerenciamento e a sincronização de arquivos e dados armazenados em serviços compatíveis com APIs do Google.

A aplicação utiliza a autorização concedida pelo usuário para acessar somente os recursos necessários ao funcionamento da funcionalidade solicitada.

Importante: o acesso aos dados do Google somente ocorre após a autorização explícita do usuário por meio do mecanismo de autorização OAuth do Google.

Como o aplicativo funciona

Quando necessário, o usuário realiza a autorização por meio do Google OAuth. Após a autorização, o aplicativo pode acessar os dados permitidos pelos escopos solicitados.

O aplicativo utiliza esses dados exclusivamente para fornecer as funcionalidades relacionadas ao gerenciamento e sincronização solicitados pelo usuário.

Dados acessados

Dependendo das permissões concedidas pelo usuário, o aplicativo pode acessar dados disponibilizados pelas APIs do Google, incluindo:

  • informações básicas da conta necessárias para autorização;
  • metadados de arquivos;
  • arquivos e conteúdos explicitamente autorizados pelo usuário;
  • informações necessárias para realizar operações solicitadas pelo usuário.

O aplicativo não solicita acesso a informações além do necessário para as funcionalidades disponibilizadas.

Uso dos dados do Google

Os dados obtidos por meio das APIs do Google são utilizados exclusivamente para fornecer as funcionalidades solicitadas pelo usuário, incluindo operações de gerenciamento, acesso e sincronização de arquivos, quando aplicável.

Os dados obtidos das APIs do Google não são vendidos, utilizados para publicidade direcionada ou utilizados para criar perfis de publicidade.

O uso das informações recebidas das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de Limited Use aplicáveis.

Compartilhamento de dados

O aplicativo não comercializa os dados dos usuários.

Os dados obtidos por meio das APIs do Google não são compartilhados com terceiros, exceto quando isso for estritamente necessário para fornecer a funcionalidade solicitada pelo usuário ou quando exigido por obrigação legal.

Segurança

São adotadas medidas técnicas e organizacionais razoáveis para proteger as informações processadas pelo aplicativo contra acesso, alteração, divulgação ou destruição não autorizados.

As credenciais e tokens utilizados para autorização devem ser tratados como informações confidenciais e não devem ser compartilhados pelo usuário.
